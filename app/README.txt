WHAT THIS IS
A private, offline-first business book (Progressive Web App). All records stay on the phone,
encrypted with your PIN. No account, no server database, no monthly fee.

HOSTING (needed once so Android can install it)
Android only installs web apps served over HTTPS. Upload the contents of this folder to any
static host. Examples:
  • Cloudflare Pages:  npx wrangler pages project create smarter-business-book
                       npx wrangler pages deploy . --project-name smarter-business-book
  • Netlify Drop (drag this folder onto https://app.netlify.com/drop) or GitHub Pages.
No build step is needed. Keep every file and folder together (sw.js must sit next to index.html).

INSTALL ON ANDROID (Chrome)
1. Open the web address in Chrome.
2. Tap "Install on home screen" on the book cover, or Chrome's ⋮ menu → "Install app"
   (some phones say "Add to Home screen").
3. Tap Install. The SMARTER logo icon appears on the home screen and opens full screen.
4. Open it once while online; after that it works with no signal.

FIRST USE
Tap "Open My Book", choose a 4–8 digit PIN, and enter it again. Write the PIN down somewhere
safe — if it is forgotten, the book can only be erased and restored from a backup.

KEEP A BACKUP
Front page → Backup & Export → "Save a full backup (records and photos)" about once a week. Keep the file in Google
Drive or email it to yourself. Backup files are NOT encrypted; keep them private.
